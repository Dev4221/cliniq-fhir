## AI features

- **Find patients:** type a plain-English description and get a filtered patient list instantly
- **Generate report:** select a report type and Claude writes a structured briefing from the patient data
- **Refresh alerts:** Claude scans the records and surfaces new care gaps and risk spikes
- **Scenario planner:** pick an intervention and Claude models the projected impact on readmissions
- **Agent activity:** a live log of what the AI agent is doing in the background
- **Group summary:** select a patient segment and Claude writes a plain-English briefing
- **Stakeholder reports:** per-audience dashboards for executives, clinical teams, governance, and finance

## Running the project

Install dependencies:

```bash
uv add requests python-dotenv
```

Set up your environment:

```bash
cp .env.example .env
# Add your ANTHROPIC_API_KEY to .env
```

Run Phase 0 exploration:

```bash
uv run python pipeline/phase0_explore.py
```

Run Phase 1 extraction:

```bash
uv run python pipeline/phase1_extract.py
```
